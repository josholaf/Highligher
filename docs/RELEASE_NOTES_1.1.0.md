# Highligher 1.1.0

Second feature release after 1.0.x.

## What's new

### Design
- Full Material 3 color system (surface containers, primary/secondary containers)
- Shape scale and refined Manrope type scale
- Warm paper light theme and deep forest dark theme

### Library & settings
- Library navigation label and tonal bottom bar
- Settings laid out in Material 3 section cards
- Clearer empty states for library and notes

### Capture
- Success confirmation after save (shows destination, then closes)
- Softer capture chrome copy ("Save selection")

### Motion
- Fade + horizontal slide transitions between Library and Settings

### Notes
- Document top app bar uses surface colors and clearer status text

## Version
- `versionName`: **1.1.0**
- `versionCode`: **6**

## Install
Debug APK: GitHub Actions **Build debug APK** (tag `v1.1.0` or workflow_dispatch with 1.1.0 / 6).

Signed release: **Build signed release APK** with tag `v1.1.0-signed` after secrets are configured.
