# Highligher 1.1.0

Second feature release after 1.0.x.

## What's new

### Design
- Full Material 3 color system (surface containers, primary/secondary containers)
- Shape scale and refined Manrope type scale
- Warm paper light theme and deep forest dark theme

### Library and settings
- Library navigation label and tonal bottom bar
- Settings laid out in Material 3 section cards
- Clearer empty states for notes

### Capture
- Success confirmation after save (shows destination, then closes)

### Motion
- Fade and horizontal slide transitions between Library and Settings
