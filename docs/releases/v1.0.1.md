# Highligher v1.0.1 — Offline-first highlights (draft)

**Tag:** `v1.0.1`  
**Status:** Draft release  
**Target:** `main` @ latest

Offline Android app for capturing system text selections into local Markdown notes.

## Highlights

- Capture via `ACTION_PROCESS_TEXT` (selection toolbar → Highlighter)
- Style-aware capture when the source provides `Spanned` text (bold, italic, underline, strike, links, size → headings)
- Obsidian-style library: collapsible folders, nested notes, continuous Markdown editor
- Obsidian-style live preview: Markdown renders inline, syntax markers hide on every line but the one you are editing
- Floating formatting toolbar above the keyboard: bold, italic, heading, lists, quote, code, link, indent
- Folder icons with searchable Lucide-style names; icons show in library and capture destination picker
- Markdown files as source of truth; Room index for search
- Full-text search across highlight text, notes and sources, with recent searches
- Debounced autosave; undo and redo; rename from the title bar
- Themes: system / light / dark
- Share note / export library via system share sheet
- Home-screen widget: last capture text and save path

## Requirements

- Android 8.0+ (API 26)
- Build with Android Studio; compile/target SDK 35

## Install (from source)

```bash
git clone https://github.com/josholaf/Highligher.git
cd Highligher
# Open in Android Studio → Run app
```

The CI build attaches `app-debug.apk` to this draft. It is unsigned for distribution; install it with `adb install app-debug.apk` or allow unknown sources on your device.

## Known limits

- Many browsers send plain text only for Process Text; styles appear only when the host app attaches spans
- No cloud sync or account backend by design
- Live preview covers the common Markdown syntax; unusual CommonMark edge cases fall back to plain source
