# Highligher v1.0.2 — Library design alignment and editor rework

**Tag:** `v1.0.2`
**Target:** `main`

This release brings the app in line with the updated design mockup and reworks the note editor.

## Changes

- Folder icons across the library and the capture destination picker now come from the searchable Lucide-named catalog, matching the mockup's long-press "Edit icon" flow
- Removed the hardcoded icon list and the non-searchable picker in favor of `core/icons` (`LucideIconCatalog`, `IconPickerDialog`)
- Capture save widget shows each folder's own icon in the save path and the folder dropdown
- Editor reworked to feel like a real note editor: proportional type at note-reading size instead of monospace, matching the preview
- Undo and redo now restore the cursor position, not just the text
- Formatting toolbar spacing and clearance above the keyboard improved

## Unchanged by design

- Home-screen highlight widget (no special change, per the mockup)
- Markdown files remain the source of truth; capture stays offline

## Install

Signed release APKs are attached by the `android-release.yml` workflow when run for this tag. Debug APKs attach as workflow artifacts on every push to `main`.
